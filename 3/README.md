# Лабораторная работа 3, вариант 9

Вычисление определителя рекурсивным разложением по первой строке. C11, POSIX Threads, фиксированный пул потоков и общая выдача задач под мьютексом.

## Сборка

Из папки `3`:

```sh
cmake -S src -B /tmp/lab3-build -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/lab3-build
ctest --test-dir /tmp/lab3-build --output-on-failure
/tmp/lab3-build/determinant -t 4 examples/matrix3.txt
```

Ожидаемый определитель: `-306`. Программа принимает размер `n`, затем `n*n` чисел по строкам. Без имени файла читает stdin. Поддерживаются размеры 1..14; рекурсивный алгоритм имеет факториальную сложность, поэтому большие размеры могут вычисляться долго.

- `-t 1..256`: максимум потоков **включая основной**, по умолчанию 1.
- `-d 0..3`: сколько верхних уровней разложения превратить в задачи; по умолчанию 2. При `d=0` задача одна, поэтому работает только основной поток.
- `-w 0..60`: задержка перед вычислениями для наблюдения потоков. Входит в напечатанное время; для замеров использовать 0.

Фактическое число потоков ограничено числом задач. Подготовка задач происходит до запуска работников. Каждый работник получает задачу под мьютексом, вычисляет её без мьютекса и добавляет результат к своей сумме. Основной поток выполняет ту же работу, затем ожидает остальных и складывает суммы.

## Linux и strace на macOS

Для проверки использован уже имеющийся локальный образ `osi-lab2-tools:local` из прошлой лабораторной. Из папки `3`:

```sh
docker run --rm -it --cap-add=SYS_PTRACE --mount type=bind,source="$PWD",target=/lab osi-lab2-tools:local bash
```

В контейнере:

```sh
cmake -S src -B /tmp/lab3-build -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/lab3-build
ctest --test-dir /tmp/lab3-build --output-on-failure
/tmp/lab3-build/determinant -t 4 examples/matrix3.txt
sh src/tools/capture-linux.sh /tmp/lab3-build/determinant /tmp/lab3-evidence
cat /tmp/lab3-evidence/ps-t4.txt
grep -E 'clone|futex|exit' /tmp/lab3-evidence/strace-t4.txt
```

Скрипт автоматически проверяет 1,2,4,8 потоков через `ps -L` и `/proc/PID/task`, сохраняя трассировки. В снимке для `-t 4` ожидаются один PID, четыре разных TID и `NLWP=4`. В strace — три успешных `clone`/`clone3` с `CLONE_THREAD` (основной поток уже существует). В этой среде `clone3` возвращает `ENOSYS`, затем glibc успешно использует `clone`.

Отдельная трассировка:

```sh
strace -f -e trace=clone,clone3,futex,clock_nanosleep,exit,exit_group -o /tmp/lab3-strace.txt /tmp/lab3-build/determinant -t 4 -w 2 examples/matrix5.txt
less /tmp/lab3-strace.txt
```

`-f` включает созданные потоки; `-o` сохраняет трассу. `pthread_create` и `pthread_join` являются библиотечными функциями, поэтому их названий в strace нет. Мьютекс без конкуренции может не выполнять системных вызовов; `futex` может относиться и к ожиданию потока в `join`.

Рецепт отдельного Linux-образа находится в `src/tools/Dockerfile`. Для выполненной проверки новый образ не собирался и пакеты не устанавливались.

## Проверки и исследование

- На macOS пройдены оба набора CTest. На исходном Ubuntu-образе пройден базовый CTest; полного Python-набора там нет, потому что Python отсутствует.
- Полный набор: 352 результата на 22 матрицах, глубинах 0..3 и лимитах 1,2,4,8. Независимый эталон — точная сумма по перестановкам. Пройден на macOS и отдельно на Linux-бинарнике в существующем Python-образе.
- 19 ошибочных входов отклонены. Проверены нулевые, вырожденные, единичные, дробные и случайные матрицы.
- ASan+UBSan: полный набор на macOS; в Linux базовый набор дополнительно с проверкой утечек. Замечаний нет. Детектор гонок не запускался.
- ОС независимо подтвердила 1,2,4,8 потоков. Фактические снимки и strace сохранены в `report/evidence`.

В ходе выполненного исследования Python-драйвер работал с хоста и запускал программу в уже работающем Ubuntu-контейнере через `--docker`. Внутренний таймер программы исключает запуск процесса и передачу входа. Размеры: 5,8,10,11; потоки: 1,2,4,8; глубина: 2; один прогрев, пять измерений. Данные и методика сохранены в `report/benchmark-*.csv` и `report/benchmark-method.json`. На 11x11 время сократилось с 1,925 с до 0,320 с, ускорение около 6,01; для 5x5 дополнительные потоки замедляют работу.
